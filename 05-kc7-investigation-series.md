# Project 05: KC7 investigation series

> **Target repo:** `incident-casebook` | **Difficulty:** Beginner to Advanced | **Time:** 1 case per week | **Cost:** Free

## Goal

Work through KC7 modules and turn each one into a professional case file. Over a few months this becomes a series that shows steady, improving investigation work.

## Why hiring managers care

It's KQL investigation work on realistic data, the same skill used in Sentinel and Defender every day. A series of well-written cases shows consistency and communication, not just puzzle solving.

## Skills you'll show

- KQL in Azure Data Explorer
- Following an intrusion across the kill chain
- Writing investigation reports for another analyst or a manager

## Prerequisites

- Free KC7 account
- The `incident-casebook` TEMPLATE.md

## Milestones

- [ ] Complete one KC7 module per week
- [ ] For each, write a case file with timeline, the key queries, IOCs and verdict
- [ ] For each, write one detection that would have caught the intrusion earlier and add it to `sentinel-detections`
- [ ] After 4 cases, write a short "patterns I keep seeing" post in the casebook README

## Deliverables

- One case file per module in `incident-casebook/cases/`
- One linked detection per case
- Updated case table in the casebook README

## Rules

- Write in your own words and show your reasoning. Don't post answer keys or flag values; focus on method and findings.

## Stretch goals

- Write a reusable KQL "investigation starter pack" of queries you use in every case
- Time yourself and note how long each case took as you improve

## Interview talking points

- Walk through one case end to end in 5 minutes (practice this; it's a great behavioral story)
- A query that changed the direction of an investigation
- How you decide when an investigation is done
